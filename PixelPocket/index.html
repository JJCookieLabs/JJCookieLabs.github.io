Comment ça marche ?

L’image garde exactement ses pixels. Les fichiers sont placés dans un bloc supplémentaire du PNG, avec compression si votre navigateur la prend en charge. Tout est traité sur votre appareil, sans connexion ni envoi à un serveur.

Les données ne sont pas chiffrées. Envoyez le PNG original comme fichier : une retouche, une capture d’écran ou une recompression peut supprimer le contenu intégré. La taille du PNG augmente avec les fichiers ajoutés. Limite de cette version : 200 Mio de données avant compression et 250 Mio par PNG.
